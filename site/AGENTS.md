## Project

This site renders the upstream Awesome Space README (orbitalindex/awesome-space). Content changes belong upstream, never in this repo. The parser in `src/lib/parse.ts` must fail loudly on unexpected input rather than drop entries. Run `pnpm check && pnpm test && pnpm build` before pushing. Set `AWESOME_SPACE_README=<path>` to build from a local copy.

## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.
